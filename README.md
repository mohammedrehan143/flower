# Fleurissant — Haute Botanique & Floral Scenography

A bespoke luxury floral atelier web application built with [Next.js](https://nextjs.org) (App Router, Turbopack) and [Tailwind CSS](https://tailwindcss.com).

## Highlights
- **Curated Scrapbook Collages**: 24 authentic atelier floral pieces across 6 core disciplines.
- **Interactive Modals**: Seamless Scrapbook collages with sticky navigation and direct WhatsApp consultation.
- **Moments in Bloom Gallery**: Filterable photo masonry with interactive lightbox and direct WhatsApp enquiry.
- **Editorial Experience**: Cinematic botanical posters and morning-fresh floral stories.
- **1-Click WhatsApp Ordering**: Direct pre-filled concierge booking.

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

## Deploy on Vercel

The easiest way to deploy this Next.js app is using the [Vercel Platform](https://vercel.com/new). Zero configuration required.
